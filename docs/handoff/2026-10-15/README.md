C4只澄清七题文字，保留模型、选项及顺序、概率阈值和复核路由。改题未让每题都改善：人员40条的细节和安排题各下降2格。

## 为什么没有上线

本轮调用前固定的诊断要求为：总一致至少85%、每题至少75%、歧义不超过25%、无歧义背书漏报0。诊断通过也不自动等于上线验收。

- 新40总一致80.4%，未达85%。
- 说话方式29/40（72.5%）、安排读感27/40（67.5%），未达逐题75%。
- 相对AI参考的32条背书/推荐有1条无歧义漏报；8条非背书有1条误报。该漏报另有三题歧义，不能直接称HTTP实际漏放。
- 初次批次使用v1，未保存完整概率向量，不能追认后补v2的完整概率检查已经通过。

因此本轮固定“不推广C4”，没有降低标准、回改参考、删除弱题或追加C5追分。生产仍用既有默认题库，评论开关关闭；评论账本在收尾核对时为0行、0批次，shadow/primary未跑，W-02未群发重导。

## 下一位从哪里接

1. 先讨论“说话方式”和“像不像安排”能否形成稳定的原子定义；安排题只衡量文本读感，不证明真实来源。
2. 复核推荐/补充经验的主要行为边界，确认新参考的真实来源。保留人员原判，不按模型输出改标签。
3. 固定新题目及参考之后另取未见样本。已分析的40条如用于改题，应转开发用途；本次80条的一次调用许可已经完成。
4. 审查具体报告后再决定J-01开放、真实带鉴权接口核查、J-02小批shadow、正式回填及W-02重导。不得虚填验收记录中的独立标注人或accepted_by。

已有标注对账、API、checkpoint/续跑和失败处理工程均已交付。接手不需要重新填旧A/B或重新实现这些接口。
