## C4的七题怎么判断

当前离线候选 `banks/candidates/comment_reader_v0.6_candidate4.yaml`，版本cb-v0.6-candidate4。只改七题的文字和选项解释；模型、问题ID/类型、闭集及顺序、歧义阈值、fill和复核路由不变。生产仍用v0.4，候选目录继续不参与runtime发现。原来仅准改S/D的C1/C3验证器不放宽，C4另用专门入口。

| 题 | 固定判法 |
| --- | --- |
| 主要行为 | 按评论主要内容。家人/本人正面使用结果为主是亲历背书；夸好处/劝用为主是推荐，即使在答疑。客观型号/流程/渠道指路不自动等于推荐；不补写不可见回复对象 |
| 点名 | 明确品牌/公司/机构/药房/店铺/平台算；通用药名/成分/剂型/方法缩写不算；不借帖子里的名字 |
| 接帖 | 读完整可见正文，自动要点只是截断提示。不同措辞也可对应具体事实/问题；同品类泛泛回应不算 |
| 细节 | 数量、时长、规格、明确属性或实质步骤可具体，不要求亲历；名字/术语/夸张数字本身不升级 |
| 语气 | 看自然叙事、短碎口语或整齐宣传表达；不是见专业词、长句或品牌就自动判文案 |
| 读者价值 | 明确下一步入口/产品搜索词/流程等优先可行动；没有这些才看经历对比是否给判断依据；只剩评价再选只有评价；其余无。不给纯术语自动加分 |
| 安排读感 | 观察突兀植入、整齐卖点、号召等组合线索；单个品牌/专业词/数字/长句不足以证明，角色标记不是身份凭证。只判读感不查真实性 |

明确题意仍可能有边界例。报告会保留AI参考与模型各自答案，不用模型结果反向改参考或阈值。
