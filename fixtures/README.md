# 公开样本的用途

`fq_notes_gate1_50.json` 的 50 篇笔记，以及 `comments_ops_sample_33.json` 的 6 篇关联帖、33 条评论，均为完全合成的工程输入。标题、正文、标识和项目均为虚构；`synthetic_*` 标识不对应生产记录。文件名和数量仅为保留脚本调用方式与输入规模，不表示仍是历史 gate1 名单。

这些输入没有人工正确答案，不能用于准确率、一致率或闸一验收。可用 `fq_shadow.py --mock` 或评论回填脚本的 `--mock` 验证输入结构和输出生成。生成 SQL 仅用于本地检查，不应作为真实账本写入。

2026-11-14 起，上述两个 fixture 文件不再装真实样本，关联 `fq_opus_gate1_50.tsv`、`fq_jev_d081_A_gate1_50.tsv` 从当前树移除。原样本的句子此前还被抄在代码、测试和几篇文档里（假供应商的详情正文、测试稿、文档举例），同日一并换成合成句或改成概述。旧文档中的 50 篇/33 评论统计是历史记录，不能用替换后的合成输入重演。新的真实评测需要获授权的私有材料、同源参考答案与独立的验证记录；不要自动把新材料或运行产物提交到公开仓。

**当前仓库仍有已获准公开的真实交接资料。** `docs/handoff/2026-10-15/README.md` 的“完整文件和公开范围”记录负责人在知悉仓库公开后，对那一批 case、已填写结果表和交接包的明确许可；`HANDOFF.md` 及 `docs/comment-line-closeout-2026-10-15.md` 也保留了出处。本次保留这批既有业务资产及授权记录，不撤回该决定，也不宣称全仓已无真实素材。该批许可不自动扩展到本目录原始 fixture 或未来素材。

**当前树里仍与原样本相同的内容在两个地方：** 一是上面这批 `docs/handoff/2026-10-15/` 的交接资料（case 阅读页、结果表、交接包），依据就是 2026-10-15 那次许可；二是 `banks/vendor/feature_questions_v0_1.yaml` 里的几行题库示例（第 172、174、178、184、444、455、456、577、655 行）重复或紧贴旧样本里的句子，该文件是 truth-vault 题库的原样副本、校验和被钉住，不能在本仓单独改，要先在 truth-vault 改题库再同步过来。按“连续 12 个字以上相同”核对只能查到其中第 577 行；隔了空格或标点的、短于 12 个字的片段要去掉空格标点、缩短窗口才查得到。核对办法和细节见 `docs/audit-fixes-2026-11-14.md`。

**本目录另有两个文件不属于这次替换：** `comment_cases.json`、`thread_cases.json` 是更早就有的评论用例，这次没有动，也不在上面“完全合成”的说法之内。它们能否留在公开仓库，待负责人答复后另行处理。

本次没有重写 git 历史、删除既有 Actions artifact 或清理 fork/cache。旧提交仍可能含原始材料；公开授权核实及后续处置由负责人另行决定。
